    Codex outage FAQ

    Is Codex down right now?

    This page checks OpenAI's official status feed live when it loads, and again every 30 seconds. If the big answer reads NO, Codex is reporting problems; YES means all systems are operational.

    Is it Codex that's down, or my internet?

    Quick checks: load another website to rule out your connection, try Codex in an incognito window or on a different network, and clear your cache. If this page shows Codex as up but it still fails for you, the problem is likely local — your network, a browser extension, or your account.

    What's the difference between "Codex" and the OpenAI API being down?

    Codex is OpenAI's coding agent (in the CLI, IDE extensions, and the cloud), while the OpenAI API and ChatGPT are separate components. They can fail independently — the API can be degraded while ChatGPT is fine, or vice versa. The service breakdown above shows each component separately.

    Where does this site get its status data?

    Straight from OpenAI's official status page at status.openai.com — the same source OpenAI publishes. We don't run our own probes or guess, so what you see here matches the official report.

    Will you email me when Codex is back up?

    Yes — that's the whole point. Pop your email in the signup box above and we'll send a single message the moment Codex recovers from a major outage (we skip brief blips so we're not spamming you), so you can get straight back to work.

    How often does Codex go down?

    Like any large online service, Codex is up the vast majority of the time but has the occasional incident — usually brief, and sometimes affecting only one component (a single model, or just the API). For the official history of past incidents, see status.openai.com.

    Is the Codex CLI down?

    The Codex coding agent — CLI, IDE extension, and cloud — is tracked in the service breakdown above. It can be down even when ChatGPT and the OpenAI API are fine, so check that specific component. If this page shows Codex as operational but it still fails for you, the issue is likely local — your CLI version, network, or auth token.

    What's the OpenAI Codex API status right now?

    The OpenAI API is shown as its own line in the service breakdown above, pulled live from OpenAI's official status feed. The API can be degraded independently of ChatGPT or the Codex agent, which is why developers often see Codex failures while ChatGPT works fine.
